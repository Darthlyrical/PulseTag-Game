Do not write any code without explicit consent from the user.

**Why:** User wants to understand and approve each step before it's implemented. This aligns with their learning style — guidance before solutions.

**How to apply:** Before writing any code (TypeScript, config files, scripts, etc.), describe what you intend to write and why, then wait for the user to say "yes", "go ahead", "do it", or equivalent. A question about how to do something is NOT consent to implement it.
